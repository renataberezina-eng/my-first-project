# Мой первый проект

## Что это
Это мой первый проект, созданный в рамках обучения работе с системой контроля версий Git и платформой GitHub. В проекте находится простой скрипт на Python, который выводит приветствие.

## Как запустить/проверить
1. Убедитесь, что на компьютере установлен Python.
2. Откройте терминал в папке с проектом.
3. Введите команду: `python main.py`
4. В консоли должно появиться сообщение: `Hello, world`

## Что я сделал(а)
- Создала локальную папку проекта и инициализировала в ней Git.
- Настроила параметры Git (имя и почту).
- Создала файл `main.py` с первым кодом.
- Сделала первый коммит и отправила файлы на GitHub.
- Разобралась с ошибками терминала и авторизацией.

## Что было сложным / что понял(а)
**Что было сложным:** 
Поначалу было сложно разобраться с терминалом и тем, как Git понимает, какие файлы нужно сохранять. Возникали ошибки с кодировкой, удалением скрытых папок и авторизацией на сайте.

**Что понял(а):** 
Я поняла, что Git — это «машина времени» для кода. Он сохраняет версии файлов, и если что-то сломается, всегда можно вернуться назад. Также я поняла разницу между локальным репозиторием (на компьютере) и удаленным (на GitHub). Главное — внимательно читать, что пишет терминал.
